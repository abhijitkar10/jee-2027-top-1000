### C-PER-01 — JEE Main 2024 · 27 Jan Shift 1 · Q45 · MCQ

Statement I: The 4f and 5f series of elements are placed separately in the periodic table to preserve the principle of classification.
Statement II: s-block elements can be found in pure form in nature.

(1) I false, II true  (2) Both true  (3) I true, II false  (4) Both false

**Answer: (3)** · key ✔

**Solution.** Placing the 14 lanthanoids and 14 actinoids inside the main table would break its width and the similarity-based grouping, so I is true. s-block metals are highly electropositive and occur only as compounds, so II is false.
