### P-UNT-01 — JEE Main 2024 · 27 Jan Shift 1 · Q1 · MCQ

Statement I: Planck's constant and angular momentum have the same dimensions.
Statement II: Linear momentum and moment of force have the same dimensions.

(1) Statement I is true but Statement II is false  (2) Both are false  (3) Both are true  (4) Statement I is false but Statement II is true

**Answer: (1)** · key ✔

**Solution.** $[h]=[E][T]=ML^2T^{-2}\cdot T=ML^2T^{-1}$ and angular momentum $L=mvr$ has $ML^2T^{-1}$, so I is true. Linear momentum is $MLT^{-1}$ but moment of force (torque) is $ML^2T^{-2}$, so II is false.
