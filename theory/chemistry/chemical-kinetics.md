# Chemical Kinetics — theory

> Questions: [../../questions/chemistry/chemical-kinetics.md](../../questions/chemistry/chemical-kinetics.md)

## Key ideas
- Rate law $r=k[A]^m[B]^n$; order from data (compare runs). Zero order $[A]=[A]_0-kt$, $t_{1/2}=\dfrac{[A]_0}{2k}$; first order $k=\dfrac{2.303}{t}\log\dfrac{a}{a-x}$, $t_{1/2}=\dfrac{0.693}{k}$; second order $\dfrac1{[A]}-\dfrac1{[A]_0}=kt$.
- First-order: $t_{99.9\%}=3\,t_{90\%}$; $t_{75\%}=2t_{1/2}$. Pressure method for $A\to nB$: $k=\dfrac{2.303}{t}\log\dfrac{P_0}{P_0-\frac{P_t-P_0}{n-1}}$.
- Arrhenius $k=Ae^{-E_a/RT}$; $\ln\dfrac{k_2}{k_1}=\dfrac{E_a}{R}\left(\dfrac1{T_1}-\dfrac1{T_2}\right)$. For steps in sequence $E_a=E_{a1}+E_{a2}-E_{a3}$ when $k=k_1k_2/k_3$.
- Steady state: $[B]=\dfrac{K_1}{K_2}[A]$ for $A\to B\to C$. Catalyst lowers $E_a$ (regenerated, e.g. Fe$^{3+}$ in $\text{I}^-/\text{S}_2\text{O}_8^{2-}$).
- Radioactive dating: age $=t_{1/2}\log_2\dfrac{N_0}{N}$.
## Common traps
- Molecularity applies only to elementary steps; order can be fractional. A straight-line $[B]$–$t$ plot means zero order in B.
