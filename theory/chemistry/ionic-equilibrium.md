# Ionic Equilibrium — theory

> Questions: [../../questions/chemistry/ionic-equilibrium.md](../../questions/chemistry/ionic-equilibrium.md)

## Key ideas
- pH $=-\log[\text{H}^+]$; $K_w=10^{-14}$ at 25$^\circ$C. Weak acid $\alpha=\sqrt{K_a/C}$, $[\text{H}^+]=C\alpha$; very weak acid ($K_aC\sim K_w$): $[\text{H}^+]^2=K_aC+K_w$.
- Salt hydrolysis: weak acid/strong base pH $=7+\tfrac12(\text{p}K_a+\log C)$; weak acid/weak base pH $=7+\tfrac12(\text{p}K_a-\text{p}K_b)$ (=7 if equal).
- **Buffer:** pH $=\text{p}K_a+\log\dfrac{[\text{salt}]}{[\text{acid}]}$ (Henderson); best when ratio 0.1–10. Blood: H$_2$CO$_3$/HCO$_3^-$.
- $K_{sp}$: for $\text{A}_x\text{B}_y$, $K_{sp}=x^xy^ys^{x+y}$; $\text{Ca}_3(\text{PO}_4)_2$: $108s^5$. Precipitation when ionic product $>K_{sp}$; common-ion lowers solubility.
- Titrations: phenolphthalein (8.3–10) for weak acid/strong base; methyl orange (3.1–4.4) for strong acid/weak base.
## Common traps
- Do not use $\alpha=\sqrt{K_a/C}$ when $\alpha>5\%$. Solubility in g/100 mL $\times10/M$ = mol/L.
