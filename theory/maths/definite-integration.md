# Definite Integration — theory

> Questions: [../../questions/maths/definite-integration.md](../../questions/maths/definite-integration.md)

## Key ideas
- $\int_a^bf(x)dx=\int_a^bf(a+b-x)dx$ (King); $\int_0^af(x)dx=\int_0^af(a-x)dx$; even/odd over $[-a,a]$; periodic functions; $\int_{-a}^{a}\dfrac{f(x)}{1+e^{g(x)}}dx$ with $g$ odd $=\int_0^af$.
- $\int_0^{\pi/2}\dfrac{f(\sin x)}{f(\sin x)+f(\cos x)}dx=\dfrac\pi4$; $\int_0^{\pi}xf(\sin x)dx=\dfrac\pi2\int_0^\pi f(\sin x)dx$. Greatest-integer integrals split at points where $[\cdot]$ jumps.
- Beta function link for $\int_0^1(1-x^k)^ndx$; Leibniz rule for derivative of integral limits.
