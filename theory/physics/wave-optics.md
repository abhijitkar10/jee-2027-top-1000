# Wave Optics — theory

> Questions: [../../questions/physics/wave-optics.md](../../questions/physics/wave-optics.md)

## Key ideas
- **Young's double slit:** fringe width $\beta=\dfrac{\lambda D}{d}$; path difference $\dfrac{yd}{D}$; $I=4I_0\cos^2\dfrac\phi2$; intensity falls to half at path difference $\dfrac\lambda4$, to a quarter at $\dfrac\lambda3$. Amplitudes $a_1,a_2$: $\dfrac{I_{max}}{I_{min}}=\dfrac{(a_1+a_2)^2}{(a_1-a_2)^2}$ (intensity ratio $4{:}1\Rightarrow9{:}1$).
- Overlap of two wavelengths: $n_1\lambda_1=n_2\lambda_2$ (smallest integers).
- **Single slit:** minima $a\sin\theta=n\lambda$; central maximum width $\dfrac{2\lambda D}{a}$; number of double-slit fringes within it $=\dfrac{2d}{a}$.
- Thin film / slab shift: $\Delta y=\dfrac{(\mu-1)tD}{d}$. Polarisation: Brewster $\tan i_B=n$, Malus $I=I_0\cos^2\theta$.
## Common traps
- Use consistent units (nm, mm). For a bright/dark fringe in a medium replace $\lambda$ by $\lambda/n$.
